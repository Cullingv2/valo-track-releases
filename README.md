# VALO//TRACK — Valo Overlay

Overlay pour Valorant : **Alt+Z** ouvre par-dessus le jeu les rangs, le pic, le winrate, le niveau et les groupes des joueurs de ta partie. Un clic sur un joueur ouvre sa carrière (rang de l'acte, historique classé, stats de tout l'acte : K/D, ACS, ADR, HS %, KAST, first bloods, clutchs…), un clic sur un match ouvre son détail complet.

## Télécharger

➡️ **[Dernière version (Windows 10 / 11, 64 bits)](../../releases/latest)** : télécharge `ValoOverlay-x.y.z-setup.exe` puis lance-le.

- Installation pour l'utilisateur courant, sans droits administrateur, raccourci dans le menu Démarrer.
- Windows peut afficher « Windows a protégé votre ordinateur » (l'installeur n'est pas signé) : **Informations complémentaires → Exécuter quand même**.
- L'application vit dans la zone de notification (icône V rouge) : clic gauche pour afficher / masquer, clic droit pour quitter.

## Utilisation

| Action | Effet |
| --- | --- |
| Alt+Z | afficher / masquer |
| clic sur un joueur | carrière du joueur |
| clic sur un match | détail du match |
| Échap | retour, puis fermer |
| glisser l'en-tête / les bords | déplacer / redimensionner |

- Mets Valorant en **plein écran fenêtré**, sinon aucune fenêtre ne peut s'afficher par-dessus.
- **Alt+Z est aussi le raccourci de l'overlay NVIDIA** : si les deux s'ouvrent, change l'un des deux (`%APPDATA%\fr.valooverlay.app\config.json`, clé `hotkey`).
- L'overlay lit uniquement le client Riot local et les serveurs Valorant avec ta session : il ne touche ni au jeu ni à ses fichiers.
